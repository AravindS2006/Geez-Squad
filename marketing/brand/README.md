# Geez Squad logo

The mark is a "G" drawn as an open ring, like a rep-progress ring. A volt dot sits in the gap; it reads as a
pose-tracking landmark and as a "live" indicator. Colours come from `src/app/tokens.css`: ink `#111111`,
white `#FFFFFF`, volt `#BEF264`.

| File | Use |
| --- | --- |
| `geez-squad-mark.svg` | Default mark on light backgrounds: app icon, favicon, video end card |
| `geez-squad-mark-inverse.svg` | Mark on ink or dark backgrounds |
| `geez-squad-mark-mono.svg` | Single-colour uses: print, stamps, watermarks |
| `geez-squad-lockup.svg` | Mark + wordmark on light backgrounds |
| `geez-squad-lockup-inverse.svg` | Mark + wordmark on dark backgrounds |

Rules:

- The smallest size is 16 px for the mark and 120 px wide for the lockup.
- Keep clear space around the mark equal to the dot's diameter (8 units on the 64-unit grid).
- Never put the volt dot on white; it has too little contrast. On light backgrounds, use the ink tile.

Limit: the lockup's wordmark is live text in Inter 800. It renders correctly only where Inter is loaded (the
Remotion project, the website). Convert it to outlines before sending it to print or third parties.
